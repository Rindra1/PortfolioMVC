Bienvenue sur mon **Portfolio personnel** développé en **ASP.NET MVC**. Ce projet met en avant mes compétences en développement web et en intégration d’API.

## Description

Ce portfolio est une application **MVC** qui récupère les données via une **API REST** hébergée dans le repository [Portfolio API](https://github.com/Rindra1/PortofolioApi).  
Il est construit avec les technologies suivantes :

- **Backend** : C# (ASP.NET MVC)
- **Frontend** : HTML, CSS, JavaScript, AJAX
- **Communication avec l’API** : AJAX pour récupérer et afficher dynamiquement les données

## Fonctionnalités

- Affichage dynamique de projets et réalisations depuis l’API
- Interface responsive et moderne
- Navigation fluide grâce à JavaScript et AJAX
- Sections typiques : À propos, Projets, Compétences, Contact
